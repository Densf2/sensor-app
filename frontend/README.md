# sensors-dashboard-frontend — Лабораторна робота №2

Клієнтський застосунок на Next.js (App Router) + Tailwind CSS для системи
моніторингу давачів. Реалізує навігаційну панель, сторінки візуалізації
графіків для двох давачів (температура, вологість) та сторінку авторизації.

## Встановлення та запуск

```bash для запуску бекенду
npm install && npm run start:dev
```

```bash для запуску фронтенду
npm install && npm run dev -- -p 3001
```

Застосунок доступний на `http://localhost:3000`.

## Структура проєкту

```
app/
  layout.tsx            # RootLayout — підключає Navbar та глобальні стилі
  page.tsx               # Головна сторінка ("/")
  globals.css             # Tailwind CSS
  dashboard-temp/
    page.tsx              # Графік температурного давача ("/dashboard-temp")
  dashboard-humidity/
    page.tsx              # Графік давача вологості ("/dashboard-humidity")
  login/
    page.tsx              # Форма авторизації (заблокована) ("/login")
components/
  Navbar.tsx               # Навігаційна панель з підсвіткою активного маршруту
```

## Маршрути

| Маршрут               | Опис                                            |
| --------------------- | ----------------------------------------------- |
| `/`                   | Головна сторінка з описом проєкту               |
| `/dashboard-temp`     | Графік показників давача температури (recharts) |
| `/dashboard-humidity` | Графік показників давача вологості (recharts)   |
| `/login`              | Форма входу з заблокованими полями та кнопкою   |

## Особливості реалізації

- **Navbar** ([components/Navbar.tsx](components/Navbar.tsx)) — клієнтський компонент (`"use client"`),
  підсвічує активний пункт меню за допомогою хука `usePathname`.
- **Графіки** — бібліотека `recharts` (`LineChart`), дані генеруються на
  клієнті випадковим чином для наочності (лінивий ініціалізатор `useState`,
  щоб не порушувати правило `react-hooks/set-state-in-effect`) та оновлюються
  раз на хвилину через `setInterval` всередині `useEffect`.
- **Login** — статична форма з `disabled` полями/кнопкою: авторизація буде
  підключена в наступних лабораторних роботах разом із бекендом.
- Проєкт створено на Next.js 16 (App Router, Turbopack) з типізованими
  хелперами `LayoutProps`/`PageProps`, які генеруються автоматично під час
  `next dev`/`next build`.

## Звʼязок з бекендом

Друга сутність давача (вологість) відповідає сутності `humidity-sensors`,
доданій у [backend](../backend) під час лабораторної роботи №1. Підключення
фронтенду до реального REST API заплановане в наступних лабораторних
роботах.
